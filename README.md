# RxRadar frozen predictions

One file per week, saved before the outcomes were known and never rewritten.
Git history is the public timestamp. Scoring rules: decisions D9 in `docs/decisions.md`
on `main`. Results: https://anoopibrampur.github.io/rxradar/track-record.html

Fields per family: `f` family key, `n` name, `p` calibrated 90-day risk, `b` band,
`r` RxRadar rank, `rr` simple-rule rank. RxRadar describes supply risk, not clinical advice.
